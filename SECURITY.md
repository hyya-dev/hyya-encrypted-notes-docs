# Security

## Report a security problem privately

If you find a security problem in hYYa Encrypted Notes, such as a way to read notes without the key, a file that makes the app leak data, or a weakness in how notes are encrypted or synced, please tell us **privately** by **[e-mail to our security team](mailto:security@hyya.com?subject=hYYa%20Encrypted%20Notes%20security%20report)**, or through [hyya.com/contact.html](https://hyya.com/contact.html). In the app, **Settings → Report a Security Issue** opens the same e-mail.

**Please don't open a public issue for it.** Issues here are public the moment they are filed.

Tell us, if you can:

- the device and system (for example: iPhone with iOS 26, a Mac with macOS 26, Android 15),
- the app's version, shown on its page in the App Store or Google Play,
- what you did and what happened.

Please never send us your notes, your passphrase or anything private. We never ask for them.

## What happens next

We read every report, reproduce the problem, fix it in an update for each platform it affects, and tell you when the fix is out.

## Which versions get fixes

Fixes ship as updates through the App Store and Google Play. The newest version on each store receives them, so keep automatic updates on.

## Security advisories

None so far. When there is one, it is listed here with its date, the platforms and versions it affects, the version that fixes it, and what you can do until you update.
